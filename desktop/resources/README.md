# Desktop app icon

Replace [icon.png](./icon.png) with your final icon, keeping the same filename.
Use a square 1024 × 1024 PNG. Transparency is supported.

The current image is a cream sleeping cat on a deep green tile. Windows, macOS, and Linux
packaging all use this file; electron-builder converts it into platform formats.
The desktop window also uses it when running from source.

After replacing it, run `npm run desktop:build` to generate new installers.

Generated with the built-in image generation tool. Prompt: a minimal cat-themed
desktop app icon for a personal finance tracker; a curled sleeping cream cat on a
muted forest-green rounded tile, transparent outside the tile, bold flat shapes,
balanced negative space, restrained stationery-inspired design, readable at small
sizes, no text, coins, charts, gloss, 3D, glow, or oversized sparkling eyes.
